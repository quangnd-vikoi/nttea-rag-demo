ChatBox Widget

Simplest way to add chat to your website.

1-Line Embed: 
<script src="chatbox.js" data-concierge-id="YOUR_BOT_ID"></script>

Test Pages

  • Standalone - Widget handles login
  • Shared MSAL - SSO with host app
  • Easy Auth - Azure App Service

More Options

<script src="chatbox.js"
  data-concierge-id="YOUR_BOT_ID"
  data-position="bottom-left">
</script>
// Or via JavaScript
ChatBox.init({
  conciergeId: 'YOUR_BOT_ID',
  position: 'bottom-right'
});
