easyauth

Test Easy Auth Mode

Widget uses Azure App Service Easy Auth (/.auth/me endpoint).

Note: This only works when hosted on Azure App Service with Easy Auth enabled, or when widget is on the same domain as an Easy Auth app.

Config:

ChatBox.init({
  conciergeId: 'test-bot',
  authMode: 'easyauth'
});

If you're already logged into the host app, widget will auto-authenticate.
